## Overview

Age of Empires II WololoKingdoms Companion is an interactive reference for the WololoKingdoms mod collection, providing complete tech trees for all WK-added civilizations, unit comparison tables, wonder and unique technology information, counter-unit suggestions, and a quick-reference civilization strengths summary for matchup preparation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Age of Empires II WololoKingdoms Companion** delivers the features you need in a clean, intuitive package.
